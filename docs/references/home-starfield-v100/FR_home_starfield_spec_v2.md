## 1. 色の修正（v1から変更なし）
- **地の色**：画面上部と下部は `#0E0D1E`〜`#101024` 程度
- **帯の中心**：代表色は `#374080` 前後。最も明るい点でも `#7688DE` を超えない
- **星雲の色の5段階**：
  - 0%（地）：`#0C0B1E`
  - 30%（帯の外縁）：`#16183F`
  - 55%（帯）：`#262E70`
  - 78%（帯の中心）：`#3E4AA8`
  - 100%（ごく一部の最明部）：`#7688DE`
- **星雲の形**：ノイズで作る濃淡に、細かい筋と暗黒帯を入れる。帯は約7°の右上がり
- **周辺減光**：四隅に向かって最大55%暗くする
- **ノイズの注意**：ノイズの乱数（ハッシュ）は、整数座標をビット演算で混ぜる方式にしない。格子状の模様が出る。sinを使う連続的なハッシュを使う

## 2. 星（作り直し）

**安っぽさの原因と対処**

| 原因 | 対処 |
|---|---|
| 十字の光条 | 廃止する |
| 輪郭のくっきりした円 | 廃止する |
| 星が画面全体に均一に散らばっている | 群れのある配置にする |

**描き方**
1. **形**
   - すべての星を、中心から外へ自然に減衰する「にじんだ光点」で描く
   - ガウス状の光点画像を1枚作り、それを縮小して描く
   - 描画半径は、芯の半径の約4.2倍
2. **配置**
   - 帯に寄せる。そのうえで、低い周波数のノイズで濃い所と薄い所を作る
   - 星が群れて見えるようにし、一様にばらまかない
3. **数と大きさ**（芯の半径）

   | 階層 | 数 | 芯の半径 | 不透明度 | 備考 |
   |---|---|---|---|---|
   | 微光星 | 約2200 | 0.18〜0.38pt | 0.18〜0.6 | 8割を帯に |
   | 中くらいの星 | 約110 | 0.42〜0.62pt | 0.55〜0.85 | |
   | 明るい星 | 9 | 0.75〜0.95pt | | 半径約10ptのごく淡いにじみ（不透明度0.07）を重ねる |

   - 明るい星は、カードの周り（横18〜82%・縦22〜70%）と画面下部（縦62%より下）には置かない
4. **色**
   - 青白 `rgb(196,210,250)`：約1/3
   - 淡い青白 `rgb(214,222,255)`：約1/3
   - 白 `rgb(236,238,255)`：約1/6
   - ごく淡い暖色 `rgb(255,240,222)`：約1/6
5. **下側**：画面高さ55%より下は、星を4割間引き、大きさを0.75〜0.8倍にする
6. **瞬き**
   - 9〜15秒に1回、明るい星から1つだけ選び、光条なしの柔らかい光で3.6秒かけて光らせて消す
   - 光らせ方：不透明度 0→0.85→0
   - 星の描画は、静止した1枚の画像にする

## 3. その他（ゆらぎ・負荷）

**ゆらぎの仕組み**：形が少し違う2枚の星雲画像を重ね、それぞれをゆっくり漂わせながら、片方の不透明度を上げ下げする。雲の形がその場で少しずつ変わって見える。

1. **星雲A**（一番下・不透明）
   - 26秒かけて往復する
   - 動きは「左に7px・下に3px」と「右に7px・上に3px」の間（イーズインアウト）
   - 端が見えないよう、常に1.06倍に拡大しておく
2. **星雲B**（Aの上）
   - Aと同じ作り方で、ノイズの位置をずらして形を変えた版
   - 19秒周期で、Aと逆向きに漂う（右下⇄左上・1.07倍）
   - 同時に、17秒周期で不透明度を 0⇄1 で往復させる
   - 周期をずらしてあるので、同じ動きの繰り返しには見えない
3. **星**（Bの上）：静止させる。ゆらがせない
4. **重なり順（下から）**
   1. 星雲A
   2. 星雲B
   3. 星
   4. 瞬き
   5. 魔法陣

   星雲は不透明なので、必ず魔法陣より下に置く
5. **負荷の方針**
   - 星雲A・B・星は、起動時と画面サイズが変わったときに1回だけ描く
   - 星雲は画面の1/2.5の解像度で描き、拡大表示する。柔らかい星雲なので劣化は見えない
   - 動きは、位置と不透明度のアニメーションだけ。GPU合成で動かし、毎フレームの描画処理は使わない
   - 旧方式の「毎フレームぼかし雲を描き直す処理」と「星を1つずつ常時点滅させる処理」は廃止する（v1と同じ）
6. **省電力**
   - 端末で「視差効果を減らす」がオンのとき：ゆらぎと瞬きを止める。星雲Bは不透明度0.5で固定する
   - アプリがバックグラウンドにあるとき：瞬きのタイマーを止める
7. **既存の要素を残す**：旧仕様の星雲の位置計算（`nebPos`）と、星を入れていた要素は削除しない（v1と同じ）
8. **フィルムグレイン**：既存のもの（不透明度0.05）はそのまま残す

## 確認方法
- 見本の静止画・動画と、実機を並べて比べる
  - 星に十字の光条がないこと
  - 星の輪郭が硬く見えないこと
  - 20秒ほど見ていると、帯の雲の形がゆっくり変わること
- ホーム画面を5分表示し続けて、端末の発熱が旧版より明らかに少ないこと
